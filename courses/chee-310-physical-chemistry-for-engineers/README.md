# CHEE 310 — Physical Chemistry for Engineers

- Credits: 3
- Term: Winter 2025
- Instructor: Sasha Omanovic
- Prereqs/coreqs/restrictions: Corequisite: CHEE 220. Not open to students having taken CHEM 233.
- Official source: https://www.mcgill.ca/study/2024-2025/courses/chee-310

## Official overview
Introduction to chemical kinetics, adsorption, surface tension, and electrochemistry. Topics emphasize applications of physical chemistry for chemical engineers.
